# 架构板 · Archboard

用细线框精确排布系统架构图的前端工具。纯静态、零依赖、离线可用，数据存在浏览器本地，不需要后端，也不需要构建。

![status](https://img.shields.io/badge/build-none-brightgreen) ![deps](https://img.shields.io/badge/dependencies-0-blue) ![size](https://img.shields.io/badge/size-~200KB-lightgrey)

## 一、这个工具解决什么问题

画架构图常见的两种方式都不太顺手：拖拽式白板（tldraw / Excalidraw）对不齐、线条粗细不一；画图软件（Figma / draw.io）功能够但重，为了一张图要开一整个设计工具。

架构板只做一件事：**在无限画布上，用统一线宽的细线框，快速摆出一张能直接交付的架构图**。所有元素都吸附网格与彼此，导出的图 2 倍分辨率，字体和描边都是矢量级的干净。

## 二、特点

| 特点 | 说明 |
|---|---|
| **零依赖、零构建** | 只有 `index.html` + `app.js` + `app.css` + `brand/`，没有框架、没有打包、没有 `node_modules`。你读到的源码就是运行的代码。 |
| **像素级对齐** | 平移与缩放都对齐到设备像素，1px 描边不会因为亚像素重采样而发虚、闪烁；缩放后按当前倍率重新栅格化。 |
| **细线框视觉** | 发丝线 + 留白 + 单一结构色，实时测量用琥珀色。没有阴影、没有渐变糊边。 |
| **结构化的对象** | 画布 / 层带面板 / 卡片 / 文字 / 图片 / 连线六类对象，不是自由画笔。 |
| **连线自动吸附** | 连线绑定到两个元素，元素移动时线跟着走，端点自动吸附到最近的边。 |
| **对齐与吸附** | 拖动时出现对齐参考线并自动吸附；工具栏提供 6 种对齐、2 种等距分布。 |
| **本地存储** | IndexedDB 存工程与图片二进制（容量以 GB 计），localStorage 只存一份引用镜像。 |
| **三种导出** | `.archboard` 工程包（ZIP，图片二进制）、纯 JSON、PNG（2 倍分辨率）。 |
| **键盘优先** | 单手就能完成建、连、选、对齐、复制、分组。 |
| **离线可用** | 首次加载后完全离线，不需要网络请求。 |

## 三、快速开始

### 本地运行

`file://` 打开会禁用 IndexedDB，请用任意静态服务器：

```bash
cd arch-editor
python3 -m http.server 8123
# 打开 http://localhost:8123
```

或者 `npx serve .`、`npx http-server` 都行。

### 部署到 Cloudflare Pages

这个项目**不需要打包**，目录本身就是产物。

```bash
cd arch-editor
npx wrangler pages deploy . --project-name archboard
```

也可以在仪表盘里：Workers & Pages → Create → Pages → **Upload assets** → 把整个目录拖进去。
接 GitHub 自动部署时，构建设置填：Build command **留空**，Build output directory **`/`**（若仓库根就是这个目录）。

### 浏览器要求

Chrome / Edge 89+、Safari 16.4+。依赖 `CompressionStream`（工程包压缩）与 `IndexedDB`。
界面按桌面端设计，未针对移动端适配。

## 四、界面

```
┌──────────────────────────────────────────────────────────────┐
│ 工具栏：工具 · 分组 · 对齐 · 撤销重做 · 吸附        导入 导出 │
├──────────┬────────────────────────────────────┬──────────────┤
│          │                                    │  检查器      │
│  图层栏  │              画布                  │  （属性）    │
│          │                                    ├──────────────┤
│          │                                    │  鸟瞰图      │
├──────────┴────────────────────────────────────┴──────────────┤
│ 提示 · 状态                                   读数 · 缩放   │
└──────────────────────────────────────────────────────────────┘
```

- **工具栏**：左边是七个工具，中间是分组与对齐，右边是导入导出。
- **图层栏**：树状结构，支持拖拽排序、显隐、锁定、重命名。`⌘\` 收起/展开。
- **检查器**：选中任何对象后在这里改属性；选中多个时是批量编辑。
- **鸟瞰图**：整个画布的缩略图，点击或拖动快速定位。`M` 显隐。
- **底栏**：左边是快捷键提示和状态，右边是坐标/选中数/元素数与缩放比例。

## 五、操作手册

### 5.1 工具与放置

| 工具 | 快捷键 | 用法 |
|---|---|---|
| 选择 | `V` / `⌘1` | 点选、框选、拖动 |
| 面板 | `P` / `⌘2` | 空白处单击放置 1800×140 的层带，再拖角点调大小 |
| 卡片 | `C` / `⌘3` | 空白处单击放置 390×92 的卡片（带图标与说明的节点）|
| 文字 | `T` / `⌘4` | 空白处单击放置 420×44 的文字，内容在右侧检查器改 |
| 图片 | `I` / `⌘5` | 空白处单击放置 96×96 占位图，再在检查器里上传；图片也可直接拖进窗口 |
| 连线 | `A` / `⌘6` | 先点起点元素，再点终点元素 |
| 画布 | `N` / `⌘7` | 空白处单击创建一块 1600×900 的画布，再拖角点调大小 |

> `⌘+数字` 在浏览器里会被占用成「切换标签页」，此时用 `⌥+1~7`，行为完全一致。
> 放完一个对象后工具会自动回到「选择」，避免误放。

### 5.2 选择与移动

- **单击**选中；**Shift + 单击**加选或取消；在空白处**按下拖动**框选。
- 拖动元素本身移动；拖动**角点**缩放，拖动**边**单向缩放。
- **方向键**微调 1px，**Shift + 方向键** 10px。
- `⌘D` 复制，`Delete` / `Backspace` 删除，`⌘Z` 撤销，`⇧⌘Z` 重做，`⌘A` 全选。
- `⌘G` 分组，`⇧⌘G` 解组。
- 拖动时会出现**对齐参考线和吸附**；按住 `Alt` 临时关闭吸附。工具栏的「吸附」按钮是总开关。

### 5.3 画布（artboard）

画布是底层的矩形区域，用来界定「一张图」的导出范围，可以有多块。

- **拖动标题条**移动整块画布（连同里面的元素）。
- 拖**角点**改画布大小；检查器里也能直接输入位置与尺寸。
- **双击名称**重命名；检查器里可设**背景色**、**背景图**与**铺法**（铺满裁剪 / 拉伸 / 平铺）。
- 「+ 画布」新建；画布检查器右下角的三个按钮分别是：缩放到此画布、导出此画布为 PNG、删除画布。
- 一个元素**完整落在**某块画布内时，就归属该画布；拖出边界即脱离。

### 5.4 连线

用 `A` 工具点起点元素、再点终点元素即可。连线不是独立浮动的线，它**绑定两个元素**：元素移动、缩放、删除时线会跟着更新。

选中连线后在检查器里可以调：

| 属性 | 取值 |
|---|---|
| 路径 | 曲线（贝塞尔）/ 直线 / 折线 |
| 线型 | 实线 / 虚线 / 点线 |
| 箭头 | 无 / V 形 / 实心三角 / 圆点 |
| 双向 | 两端都画箭头 |
| 颜色、粗细 | 单独设置 |

端点会自动吸附到目标元素**最近的边**，不用手动对位置。

### 5.5 分组与对齐

- 选中多个对象后 `⌘G` 分组，分组在图层栏里表现为可折叠的节点，整体移动和缩放。
- 工具栏对齐区：左 / 水平居中 / 右 ‖ 顶 / 垂直居中 / 底 ‖ 水平等距 / 垂直等距。
  单选时以画布为参照，多选时以选区外接框为参照。
- 检查器里的「居中画布 / 居中于画布」把选区摆到所属画布正中。

### 5.6 图层

- 树状列出全部对象，**拖动**可调整上下顺序与分组归属。
- 每行右侧两个按钮：**显示/隐藏**、**锁定/解锁**（锁定后画布上不可拖动）。
- **双击名字**重命名；分组节点左侧的三角可折叠。
- 隐藏的对象不参与导出。

### 5.7 视图：缩放与平移

| 操作 | 手势 |
|---|---|
| 平移 | 空格 + 拖动、鼠标中键拖动、触控板双指滑动 |
| 缩放 | 滚轮 / 触控板捏合、`⌘/Ctrl + 滚轮`、工具栏右侧的缩放读数 |
| 缩放到全部内容 | `0` 键，或点击右下角的缩放百分比 |
| 鸟瞰图 | `M` |

缩放比例显示在**右下角**，两侧的 `−` `+` 是步进缩放；点百分比等于「适应窗口」。
窗口尺寸变化后视图不会跳动，缩放锚点始终是光标位置。

### 5.8 检查器

选中对象后在右侧调整，改动即时生效：

- **通用**：位置、尺寸、圆角、透明度、上移/下移一层。
- **层带面板**：标签、强调色、背景色与透明度、背景图。
- **卡片**：标题、说明、强调色、图标（上传 PNG/SVG）、布局（图标左 / 图标上）、小圆点。
- **文字**：内容、字号、颜色、对齐。
- **图片**：更换图片、填充方式（铺满裁剪 / 拉伸 / 平铺）。
- **画布**：名称、位置、尺寸、比例锁、背景色、背景图、铺法。
- **多选**：宽高、圆角、透明度、颜色、图标、布局可批量套用；留空的项不改变。

### 5.9 颜色

颜色控件带色板与调色盘，支持**透明度**（面板背景、元素颜色都能单独设 alpha）。
主题本身很克制：结构用中性白，实时测量用琥珀色，强调色从六个预设里选。

### 5.10 存储、导入、导出

**自动保存**：任何改动都会在 350ms 后写入 IndexedDB（图片以二进制存 `assets` 表，模型里只存 `asset:<hash>` 引用），localStorage 仅保留一份轻量镜像。关掉页面、断网都不丢。

**导出**（右上角图标）：

| 操作 | 产物 | 说明 |
|---|---|---|
| 点击「导出」 | `架构板-<时间>.archboard` | ZIP 工程包：`meta.json` + `model.json` + `assets/`，图片按二进制存，体积最小 |
| `⇧` 点击 | `架构板-<时间>.json` | 纯 JSON，图片以 base64 内嵌，便于 diff / 版本管理 |
| `⌥` 点击 | `架构板-<时间>.png` | 2 倍分辨率位图；选中某块画布时只导出该画布 |

**导入**：点右上角导入按钮选文件，或者直接把 `.archboard` / `.json` **拖进窗口**。
导入会替换当前工程（可 `⌘Z` 撤销）。

| 工具 | `⌘1`~`⌘7` 或 `⌥1`~`⌥7` | 同上，按工具栏顺序 |
| 编辑 | `⌘Z` / `⇧⌘Z` | 撤销 / 重做 |
| 编辑 | `⌘D` | 复制选中 |
| 编辑 | `⌘A` | 全选 |
| 编辑 | `Delete` / `Backspace` | 删除选中 |
| 编辑 | `⌘G` / `⇧⌘G` | 分组 / 解组 |
| 编辑 | `方向键` / `Shift+方向键` | 微调 1px / 10px |
| 编辑 | `Esc` | 取消选择、回到选择工具 |
| 视图 | `空格 + 拖动` / 中键拖动 | 平移 |

## 六、文件格式

`.archboard` 是一个普通 ZIP：

```
meta.json      # 版本、时间、元素数、图片数、作者信息
model.json     # 完整模型：elements / canvases / layers / bg
assets/        # 图片，文件名是内容哈希，扩展名保留原格式
```

`model.json` 里的图片字段是 `asset:<hash>`，导入时按哈希从 `assets/` 还原成 data URL。
同名 `.json` 导出则是把图片直接内嵌成 base64，结构和 `model.json` 一致。

## 七、数据与隐私

- 所有数据都在**你自己的浏览器**里，没有任何服务端请求，没有埋点、没有统计。
- 图片以二进制存进 IndexedDB，同样的图只存一份（按内容哈希去重）。
- 清除浏览器数据 = 删除工程。重要图纸请用「导出」留一份 `.archboard`。

## 九、设计取舍

- **用 DOM 而不是 canvas 渲染对象**：文字能被浏览器原生排版，任何缩放下都清晰；元素天然可聚焦、可无障碍读取；调试时能直接在开发者工具里看到结构。箭头单独用一层 SVG，因为需要精确的路径与箭头裁剪。
- **不提升 `will-change`**：合成层会让小数倍率下的 1px 描边换一种栅格化方式，拖动开始的瞬间整屏边框会跳亮。宁可每帧重绘（实测 p95 ≈ 14ms），也要保证「静止 / 拖动」外观完全一致。
- **位移对齐整像素**：亚像素平移会让网格点和细线被逐帧重采样，在 1x 外接屏上表现为闪烁。
